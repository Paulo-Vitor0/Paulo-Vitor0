## 🧑‍💻 Sobre mim

> **"Todo grande projeto começa com uma pequena ideia."** 💡

Olá! Eu sou o **Paulo**, estudante do **2º ano do Ensino Médio** e do **Ensino Técnico em Desenvolvimento de Sistemas no CEPI Osvaldo**.
